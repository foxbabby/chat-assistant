<h1 align="center">聊天助手</h1>
<p align="center">macOS 上的微信与钉钉聊天助手 · 云端模型 · 多种回复风格</p>

聊天助手使用你配置的云端模型，为选定会话生成并发送回复。微信和钉钉可同时监听，在主页面切换查看各自的消息和状态。基于 jev-jarvis 0.3.0 的 MIT 源码改造，保留原作者 eatmoreduck 的版权声明。

## 功能

- **云端模型**：默认提供 DeepSeek 配置，可修改 API 地址、API Key 和模型名称，支持 OpenAI 兼容的 HTTPS 聊天接口。没有本地大模型推理。
- **六种回复风格**：自然友好、高情商、简洁专业、轻松幽默、温柔耐心、礼貌婉拒，主页面随时切换。
- **微信**：通过 macOS 辅助功能读取当前会话；支持文字回复及本地原创表情卡片。
- **钉钉**：选择一个会话，通过 dws 实时事件连接监听，无新消息时不轮询聊天接口、不调用模型。
- **图片理解**：钉钉图片默认使用系统 OCR 提取文字，也可单独配置云端视觉模型理解画面。
- **个人表达**：在设置中维护自己的语气、表达示例和工作知识。
- **工作答疑**：可读取用户自行填写的知识、本机文档索引及通过环境变量指定的本地 SPD 源码。资料不足时先询问具体情况；启用工作知识后，检索前可先发送“我查一下相关资料，稍等。”，随后再回复结论。
- **发送控制**：排除指定人员、去重、发送前复核、发送结果确认；启动默认不回复历史消息，也可勾选立即处理最后一条。

## 系统要求

- macOS 14 或更高版本，目前不支持 Windows。
- [uv](https://docs.astral.sh/uv/)；Python 3.12 由 uv 管理。
- Xcode Command Line Tools，用于编译 Swift 原生启动器。
- 可用的云端聊天 API 账号及额度。
- 微信桌面客户端及辅助功能权限；钉钉功能另需安装并登录 dws CLI，默认路径为 `~/.local/bin/dws`。

钉钉依赖的 CLI 必须支持 `chat`、`profile`、`event` 等命令及实时消息订阅。dws 不随本仓库分发；没有配置 dws 时仍可单独使用微信功能。

## 安装和启动

```bash
git clone https://github.com/foxbabby/chat-assistant.git
cd chat-assistant
xcode-select --install  # 已安装则跳过
uv sync --frozen --python 3.12
.venv/bin/python src/app.py
```

也可以双击 `start.command`。首次运行需要联网安装依赖。生成的应用位于 `dist/聊天助手.app`。

仅构建应用：

```bash
.venv/bin/python packaging/build_app.py
```

构建按当前 Mac 的 CPU 架构生成，未做 Apple Developer ID 签名或公证。App 启动仍需要 uv，并会在本机创建运行环境，因此不是无需任何依赖的独立安装包。

## 使用

1. 打开设置，填写聊天 API 地址、密钥和服务商实际可用的模型名称，测试连接后保存。
2. 使用微信时，点击申请辅助功能授权，在系统设置中打开“聊天助手”的开关。系统开关需要本人确认；若后台权限未生效，退出并重新打开应用。
3. 打开微信目标聊天，选择回复风格，再开启微信自动回复。切换联系人会暂停，需要对新会话重新开启。窗口隐藏、最小化或其他桌面中的会话不保证能够读取；发送准备完成后会将微信置前并复核。
4. 使用钉钉时，在设置中登录、读取账号并加载会话，再在主页的可输入下拉框中筛选、选择目标会话并开启。钉钉不要求窗口保持前台；实时连接中断时会暂停并提示。
5. 开启按钮下面的“开启时立即回复最后一条”默认关闭。勾选后仍经过排除人员、消息稳定性和去重检查，不保证一定发送。
6. 设置中可维护自己的昵称、无需回复的人员、表达习惯和工作知识。钉钉图片可选系统文字识别或单独配置视觉 API；目前不会自动复用聊天模型作为视觉模型。

两个平台独立开启和暂停。关闭应用会停止两边，重新打开默认暂停。

## 费用与数据

- 系统 OCR 在本机运行，不收取模型识别费用。生成回复及云端图片理解按所配置服务商计费。
- 最近的聊天上下文、相关个人表达与工作知识会发送到你配置的模型服务；云端视觉模式也会上传待识别图片。
- 密钥保存在 `~/Library/Application Support/微信聊天助手/settings.json`，文件权限为 `0600`，不是加密钥匙串。
- 旧名称的数据目录用于兼容已有配置；发送去重账本也存放在这里。
- **公开版不包含作者的账号、聊天记录、学习档案、企业知识库标识或企业源码。** 工作答疑只读取用户自行提供的资料；没有附带跨 Codex 项目的自动学习任务。
- 需要从本地 SPD 源码补充答疑时，先确保自己有权使用该源码，再设置 `CHAT_ASSISTANT_SPD_SOURCE_ROOT` 为源码根目录，并在应用设置中启用工作知识。公开仓库不提供企业源码或测试数据库连接；可选的文档索引应放在应用数据目录的 `spd-documents/index.json`，该目录不会提交到 GitHub。
- 支持读取本机自行提供的 `learned-profile.json`（`voice`、`examples`、`knowledge` 字段），手动维护的表达要求优先。请只填写有权使用的信息。

## 已知边界

- 微信辅助功能接口可能无法提供发送者或气泡方向。助手自己发送的内容会持久化去重，但手工发送的消息在发送者未知时仍可能被误当作新消息；相同会话内重复文本也可能被跳过。
- 微信不依赖截图判断图片内容；图片/表情按可见描述选择本地回复卡片，不保证能理解原图。
- 微信需要使用 Return 发送。已有草稿、会话变化或无法确认发送结果时会停止发送；不会自动重发不确定的内容。
- 工作问题证据不足时会询问具体情况；若已发送“稍等”，查询失败会再发送进度说明。图片识别失败时会请求文字补充。模型仍可能出错，请先在测试会话中验证。
- 客户端版本、macOS 权限和 dws 接口变化可能影响功能。自动化测试通过不等于已在你的设备和会话中验证实际发送。

## 开发与测试

```bash
.venv/bin/python -m unittest discover -s tests -v
node --check web/app.js  # 可选，需要 Node.js
```

`src/` 为 Python 服务及平台适配器，`web/` 为界面，`packaging/Launcher.swift` 为原生 macOS 启动器。调试 Web 界面可运行 `.venv/bin/python src/server.py`，仅监听 `127.0.0.1:18766`；不能与桌面应用同时占用该端口。
